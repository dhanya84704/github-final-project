# Simple Interest Calculator

## Introduction
This project explains how to calculate simple interest using the principal amount, rate of interest, and time period.

## Formula
Simple Interest = (Principal × Rate × Time) / 100

## Inputs
- Principal: The initial amount of money.
- Rate: Annual interest rate in percentage.
- Time: Time period in years.

## Example
Principal = 1000
Rate = 5%
Time = 2 years

Simple Interest = (1000 × 5 × 2) / 100 = 100

Total Amount = Principal + Simple Interest = 1100

## Features
- Calculates simple interest.
- Explains the formula.
- Provides an example calculation.

## Conclusion
This project helps beginners understand and calculate simple interest easily.
